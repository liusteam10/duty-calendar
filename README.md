# 值班中枢 MVP

这是单位值班日历的可交互原型，包含：

- 响应式公开月历：白班、夜班、带班领导及当天详情
- 员工个人值班视图和统计
- 互换班次、公开代班申请与状态流转演示
- 管理后台：草稿/发布提示、人员统计、发布检查、操作日志
- 已发布月份支持“创建编辑草稿 → 按日编辑 → 再次发布”，编辑期间原发布版本继续对外展示
- 微信小程序页面骨架：值班、申请、我的三个 Tab

## 运行网页原型

直接用浏览器打开 `index.html` 即可。演示数据保存在浏览器 `localStorage`，点击管理后台可以模拟草稿发布，点击换班中心可以模拟申请状态变化。

## 无服务器上线方案：CloudBase

本项目采用微信云开发作为正式后端候选，不需要自行购买 VPS。CloudBase 提供数据库、云函数、身份认证和托管能力；微信小程序可以直接通过内置 SDK 访问云服务。

1. 在微信公众平台注册/认证小程序，取得真实 AppID。
2. 在微信开发者工具中打开“云开发”，创建生产环境并取得环境 ID。
3. 将环境 ID 填入 `miniprogram/app.js` 的 `CLOUD_ENV_ID`。
4. 部署 `miniprogram/cloudfunctions/health`，确认小程序能调用健康检查。
5. 再部署排班、换班和管理员云函数，并在云数据库建立人员、班表、申请和审计集合。

CloudBase 的小程序 SDK 已内置在微信小程序运行框架中，支持直接访问数据库和云函数，详见 [腾讯云 CloudBase 小程序 SDK](https://cloud.tencent.com/document/product/876/19385)。

## 接入真实系统时

`miniprogram/` 是微信开发者工具可继续开发的页面骨架。需要补齐：

1. CloudBase 云函数中的微信身份绑定和业务规则。
2. 人员档案、班表、换班申请和审计日志集合。
3. 云数据库事务与版本号，保证公开代班的首个接受者获胜。
4. 微信订阅消息模板、隐私指引和正式小程序审核配置。

## 导入微信开发者工具

选择 `miniprogram/` 作为项目目录，并把 `project.config.json` 中的 `touristappid` 替换为单位真实 AppID。当前项目里的 `apiBaseUrl` 也是占位地址，未接入真实服务端前只能用于界面体验，不能直接提交正式审核。
